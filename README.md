# AD-TRF

This repository contains the analysis code for microbial (metagenomics), untargeted metabolomics, host transcriptomics, and targeted bile acid changes in the APP23 Alzheimer's disease mouse model subjected to time-restricted feeding (TRF). We previously showed that TRF improves cognition, sleep, and neuropathology in AD mice ([Whittaker et al., 2023](https://doi.org/10.1016/j.cmet.2023.07.014)). In this study, we build on that work by characterizing the microbial and metabolomic changes induced by TRF to understand the mechanisms through which TRF improves AD pathology.

## Instructions on Data Access

### Mouse

Metagenomics microbiome data is available in Qiita [https://qiita.ucsd.edu] under the study ID 14708 and in ENA under project XXXXX (RNA-seq is also deposited here). Untargeted metabolomics data is available in the MassIVE database [https://massive.ucsd.edu/] under the MassIVE ID MSV000090950. Feature based molecular networking data is available on [GNPS](https://gnps2.org/status?task=94a1fd66439244d6a5b89d5e52327a89).

### Human

We used the [Dilmore, et al. 2023](https://doi.org/10.1002/alz.13007) BEAM cohort metagenomics and untargeted metabolomics data for validation. Metagenomics microbiome data is available in Qiita [https://qiita.ucsd.edu] under the study ID 13662. Untargeted metabolomics data is available in the MassIVE database [https://massive.ucsd.edu/] under the MassIVE ID MSV000087087.

## Organization of Files

Each main folder relates to one of our six main figures/analysis. Within these folder we have `data`, `results`, and `code`.

- `code` holds the scripted used for analysis.

- `data` has the required input files needed to run the code.

- `results` contains the outputs of running the code.
